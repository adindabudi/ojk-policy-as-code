# Support

## How to file issues and get help

This project uses GitHub Issues to track bugs and requests. Search the existing issues before you open a new one. Remove tenant, subscription and resource IDs, resource names and OJK approval letter numbers from anything you post.

This repository is a sample. It's provided as-is and maintained on a best-effort basis, with no service level.

- For questions about Azure Policy, Azure Arc or other Azure services, use [Azure support](https://azure.microsoft.com/support/options/) or [Microsoft Q&A](https://learn.microsoft.com/answers/).
- For questions about OJK (Otoritas Jasa Keuangan, the Indonesian Financial Services Authority) regulations and how they apply to your bank, talk to your compliance team.
- For security issues, follow [SECURITY.md](SECURITY.md) instead of opening an issue.
